# Confidential Computing Consortium (confidential-computing-consortium)
The Confidential Computing Consortium (CCC) is a Linux Foundation project that brings together hardware vendors, cloud providers, and software developers to accelerate the adoption of confidential computing. It protects data in use via hardware-based trusted execution environments (TEEs).
